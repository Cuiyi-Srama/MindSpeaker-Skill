# 写作去AI味（流程层）

一套**写作流程** skill，管的是动笔之前那一步：谁在说。

它不自称能"去 AI 味"。字面清洗交给现成的成熟 skill，它只负责那些 skill 都不管的一段——**在没有具体的说话人之前，不要开始写。**

---

## 它补的是哪个空

现有的去 AI 味 skill 分三类：

- **清洗类**：稿子写完之后删掉什么（Humanizer-zh、qu-ai-wei、说人话、lieflat-less-ai-tone）
- **风格建模类**：像谁写的（umani、renhua、liam-page-writing）
- **逐段协作类**：一段一段来（rui-writer）

三类都在处理**稿子**。没有一类在动笔之前先逼出一个具体的说话人状态。

rui-writer 最接近，但它审的是段落意图（"这一段你想表达什么"），不是人的状态。逐段流程里填一个通用意图，稿子结构对了，里面还是没有人。

本套件只填这个空：

1. 人物审问四题：谁在说 / 为什么想说 / 讲到哪会停 / 说话什么毛病
2. 素材三类：具体设备动作 / 翻车过程 / 观察者反应
3. 情绪线：先画线再写
4. 三重检验：谁在说 / 哪句替读者鼓掌 / 哪句念出来端着

其余全部委派。

## 安装

放进 skills 目录：

```
skills/写作去AI味/
├── SKILL.md
├── 00-审问与素材.md
├── 01-委派与缺口.md
├── 02-场景B-口播稿.md
├── 03-场景A-重构.md
├── 04-场景D-长文.md
├── 05-场景C-风格建模.md
└── 06-场景E-轻清洗.md
```

上游清洗 skill 已内置在 `vendor/`（humanizer-zh、qu-ai-wei、shuorenhua），随仓库一起分发，无需单独安装；对上游的改动只有 description 前缀，用于关闭独立触发。

## 一句实话

这套东西的终点是让人不再需要它——用几次之后，动笔前会自然先问"谁在说"，而不是先问"怎么写"。
